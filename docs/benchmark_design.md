# CommFormaBench: 通信算法公式→Verilog 基准测试集

> 核心思想：以数学公式为 spec 输入，系统覆盖通信系统各层的硬件化算法

---

## 基准集分类体系

按通信系统物理层处理链路组织：

```
发射端: 信源→编码→调制→MIMO→上变频→DAC
接收端: ADC→下变频→同步→均衡→解调→译码→信宿
```

---

## 评估维度 (每题)

对每个 benchmark 题目，评估以下指标：

| 维度 | 指标 | 说明 |
|------|------|------|
| **Pass@1** | 首次生成通过率 | Verilator 编译+仿真通过 |
| **Pass@k** | k次尝试内通过率 | 含迭代修正 |
| **迭代次数** | 达到正确所需迭代轮数 | Agent 反馈循环次数 |
| **并行度** | ILP 值 | 数据流图独立运算数 |
| **资源** | LUT / FF / DSP / BRAM | Yosys / Vivado 综合 |
| **频率** | Fmax (MHz) | 时序分析 |
| **吞吐率** | 样本/秒 或 bit/秒 | 流水线深度 × Fmax |
| **位精确性** | vs 浮点 golden 的 MSE | 量化质量 |
| **变换数** | LLM 发现的有效变换 | 手工评审 |
| **代码行数** | 生成的 Verilog LOC | 复杂度指标 |
| **vs HLS** | 资源比 / 性能比 | 与 Vivado HLS 对比 |
| **vs 手工** | 资源比 / 性能比 | 与开源参考实现对比 |

## 分级实验策略

考虑到硕士论文时间限制，建议分三批：

### 第一批（核心验证，必做 15 题）
选取每个类别最有代表性的题目：
- 1.3 CORDIC, 1.10 向量内积

## 基准集的学术贡献

这个 benchmark 本身就是一个独立贡献：
1. **首个通信算法公式→Verilog 的基准集**（类比 VerilogEval 但专注通信+公式输入）
2. **覆盖完整物理层处理链**
3. **每题提供标准数学公式 + Golden Model + 评估标准**
4. **可复用性**：其他研究者可用此 benchmark 评估新方法
